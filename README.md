# 关键词唤醒 (astrbot_plugin_keyword_wake)

群里出现指定关键词时，让机器人**按概率**接话。关键词匹配、概率、冷却全部在**模型之前**完成，没命中的消息不消耗任何 token。

## 安装

**方式一：从文件安装（推荐给普通用户）**

1. 拿到 `astrbot_plugin_keyword_wake.zip`
2. AstrBot WebUI →「插件」→ 右下角 ➕ →「从文件安装」→ 选这个 zip
3. 装完在插件列表里点「配置」，填上你的关键词

**方式二：从目录安装**

把 `astrbot_plugin_keyword_wake/` 整个文件夹放进 AstrBot 的 `data/plugins/`，重启 AstrBot。

要求 AstrBot ≥ 4.24.0。

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enabled` | 开 | 总开关 |
| `keyword` | 空 | **必填**。消息正文包含它就算命中，大小写不敏感 |
| `probability` | 0.5 | 命中后真的接话的概率 |
| `cooldown_seconds` | 30 | 同一个群的冷却时间 |
| `group_whitelist` | 空 | 只在这些群号生效；留空 = 所有群 |
| `bot_ids` | 空 | 要忽略的机器人 QQ 号 |

改完配置即时生效，不用重启。

## 它怎么工作

AstrBot 收到群消息后，会先问插件"这条消息要不要处理"，再决定要不要调模型：

```
群消息 ──> 唤醒阶段（本插件在这里判断，0 token）
             ├─ 是私聊？            → 不管
             ├─ 不在白名单群？      → 不管
             ├─ 发送者是机器人？    → 不管
             ├─ 正文没有关键词？    → 不管   ← 绝大多数消息走到这里就结束
             ├─ 冷却中？            → 不管
             └─ 掷骰子通过 ──> 唤醒 → 交给模型生成回复（这才开始花 token）
```

## 几个容易踩的坑

**1. 只匹配纯文本，@ 昵称不算**
有人 @ 一个叫「xxx大肥鱼」的机器人时，消息文本里会出现那个昵称，本插件只看纯文本段，不会误判成自己命中。

**2. 其他机器人要学会"拉黑"**
OneBot v11 协议不标记"谁是不是机器人"。如果群里有别的 bot 会说出你的关键词，把它 QQ 号填进 `bot_ids`，否则它一说话就会把你唤醒（两个 bot 可能互相接话、无限循环）。

**3. 关键词别太常见**
「草」「哈哈」这种词会让它频繁接话，既刷屏又烧 token。建议用**只指向它自己**的词。

**4. 别在群里全量回复**
这个插件的设计是"稀有命中 + 冷却"，不是"每条都回"。真要全量，把 AstrBot 的 `wake_prefix` 置空即可，但个人号群聊全量回复很容易被风控。

## 和其他功能的关系

- 被本插件唤醒的消息，同样会带上 AstrBot 的**群聊上下文**（如果开了 `group_icl_enable`），所以它能接上刚才的话题
- 群里直接 @ 机器人是另一套唤醒逻辑，与本插件互不影响
- 冷却按群计算，不同群互不干扰
